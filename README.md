## Описание проекта

Программа строит множество Мандельброта в окне tkinter.
Для каждой точки рассчитывается последовательность, а цвет зависит от
числа итераций до выхода за радиус 2. Можно увеличивать выбранные участки.

## Функциональные возможности

### Основной функционал

- Начальная область: от -2 до 2 по обеим осям, центр в начале координат.
- Расчёт через действительную и мнимую части без типа `complex`.
- Постепенная отрисовка с отображением масштаба и процента готовности.

### Дополнительный функционал

- Красная визуализация с плавными переходами цвета и сглаживанием краёв.
- Увеличение и уменьшение масштаба кнопками или щелчком мыши.
- Сброс к исходной области.

## Требования к системе

- Python 3.9 или выше с поддержкой tkinter.
- Windows, Linux или macOS с графическим рабочим столом.
- Из стандартной библиотеки используются `tkinter` и `math`.
- Сторонние библиотеки не нужны; `requirements.txt` содержит пояснение.

## Установка и запуск

### 1. Получение проекта

```bash
git clone https://github.com/shkarupinsergey/Mnojestvo_Mandelborta.git
cd Mnojestvo_Mandelborta
```

### 2. Создание и активация виртуального окружения

В проект включено локальное окружение `venv`, как требуется в памятке.
На другом компьютере его нужно пересоздать: пути в окружении зависят
от установленного Python и расположения папки.

Windows, командная строка cmd:

```bat
python -m venv venv
venv\Scripts\activate.bat
```

Windows, PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Если PowerShell запрещает активацию, используйте cmd и команды выше.

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

Если tkinter отсутствует, на Windows установите компонент Tcl/Tk через
установщик Python; на Ubuntu/Debian установите пакет `python3-tk`.

### 3. Проверка зависимостей

```bash
python -m pip install -r requirements.txt
```

Команда ничего не устанавливает: используются стандартные библиотеки.

### 4. Запуск

```bash
python main.py
```

### 5. Управление

| Действие | Результат |
| --- | --- |
| Левая кнопка мыши по картинке | Увеличить в 2 раза и поставить точку в центр |
| Правая кнопка мыши | Уменьшить в 2 раза с центром в выбранной точке |
| Кнопка «Увеличить» | Увеличить в 2 раза относительно центра |
| Кнопка «Уменьшить» | Уменьшить в 2 раза относительно центра |
| Кнопка «Сброс» | Вернуть начальную область |

Максимальная ширина области - 4, минимальная - 0.000001.
При достижении границы масштаба соответствующее действие ничего не меняет.

1. Запустите `python main.py` и дождитесь появления изображения.

## Как работает расчёт

Для каждой точки `c = cx + i * cy` начинаем с `x = 0`, `y = 0`.
Формула `z = z² + c` записывается через действительные числа:

```text
новый x = x² - y² + cx
новый y = 2 * x * y + cy
```

Обе новые координаты вычисляются по старым `x` и `y`.
Если `x² + y² > 4`, точка выходит за радиус 2 и получает оттенок красного.
Число итераций уточняется логарифмической формулой для плавного цвета.
Если за 200 итераций выхода нет, точка окрашивается в красный.
В каждом пикселе усредняются четыре пробы для сглаживания края.
Это приближённая проверка: у границы при сильном увеличении
может потребоваться больше итераций.

Расчёт идёт по две строки, чтобы окно отвечало на действия.
Новые строки сразу появляются на экране. При увеличении масштаб и процент
готовности обновляются сразу; повторное действие отменяет старый расчёт.
Автоматического повторного построения после завершения нет.

Начальное окно - квадрат `[-2; 2] × [-2; 2]`, содержащий круг радиуса 2.
Масштаб по осям одинаковый, поэтому фигура не растягивается.
